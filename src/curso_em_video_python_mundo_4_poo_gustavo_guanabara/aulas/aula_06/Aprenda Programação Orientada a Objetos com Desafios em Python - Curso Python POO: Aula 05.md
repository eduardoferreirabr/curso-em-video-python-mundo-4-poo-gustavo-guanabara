# Fase 06 - Hora dos Desafios


## Desafio 016:

- crie classe Funcionario, onde podemos cadastrar nome, setor e cargo.
- crie também um método que permita ao funcionário se apresentar.

## Desafio 017:

- crie a classe Produto, onde podemos cadastrar nome e preço.
- crie também um método que mostra uma etiqueta de preço do produto.

## Desafio 018:

- crie uma classe Churrasco, onde seja possível informar quantas pessoas vão participar e mostre quanto de carne deve ser comprado, o custo total do churrasco e o preço por pessoa.

## Desafio 019:

- crie uma classe Livro, que vai simular a passagem de páginas de um livro, considerando também se o usuário chegou ao fim da leitura.

## Desafio 020:

- crie uma classe Gamer, onde podemos cadastrar nome, nick e os jogos favoritos de uma pessoa.
- crie também um método que permita mostrar a ficha desse gamer.

## Desafio 021:

- crie a classe Caneta, que simule o funcionamento de uma caneta colorida, podendo escrever frases na cor relativa.

## Desafio 022:

- crie a classe ControleRemoto, onde vamos simular o funcionamento de um controle
- simples (canal, volume e liga/desliga)
